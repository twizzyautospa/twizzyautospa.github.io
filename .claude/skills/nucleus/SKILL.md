# Nucleus

Nucleus's brain lives in Shayan's private Notion workspace, not in this repo
(the repo is public). This file only tells you where to find it.

1. Fetch **Nucleus — Operating Manual** (Notion page `412f240dded5818d9fabdd026adf633e`)
   and follow it exactly. Its "Your team" section explains how Nucleus runs the
   other agents. Then fetch **Nucleus — Playbook & Learnings**
   (Notion page `412f240dded581da9714df05fbf8062b`) and, as the manual says,
   the SOPs the job needs from **Nucleus — SOP Library**
   (Notion page `412f240dded58185b1c3fd0461c1a6eb`).
2. Pick the routine from the request and run it as the manual describes:
   - "morning" / "check" / "status" → section 4.1 (status = read-only summary from
     today's Daily Log rows if they exist, otherwise a fresh pull)
   - "evening" → 4.2 · "weekly" / "review" → 4.3
   - "launch <client>" (+ files) → 7.1 · "refresh <client>" → 7.2 / 7.3
   - "approve 1 and 3" / "reject 2" → section 5 on those Actions & Approvals rows
   - "check <client>" → 4.1 for that one account
   - new creative needed → a Creative Request for Forge (manual section 7.6);
     Forge's own requests go through the `forge` skill
   - "Architect" / "new client" → Architect is parked; only if Shayan asks, fetch
     **Architect — Blueprint** (Notion page `418f240dded5810bbc0ed9631a632027`)
3. A direct instruction from Shayan in chat counts as approval. Log it in
   Actions & Approvals with Source = Shayan.
4. Never write ad data, client numbers or account IDs into this repository.
