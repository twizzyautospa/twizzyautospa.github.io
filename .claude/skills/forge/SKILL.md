# Forge

Forge's brain lives in Shayan's private Notion workspace, not in this repo
(the repo is public). This file only tells you where to find it.

1. Fetch **Forge — Creative Manual** (Notion page `418f240dded5811da9e0c266e5fbd325`)
   and follow it exactly. Then fetch **Nucleus — Playbook & Learnings**
   (Notion page `412f240dded581da9714df05fbf8062b`) and, for statics and copy,
   SOP 3 (`412f240dded5819f85d3fbd8d1b7159d`) and SOP 4 (`412f240dded581f49b99f21cedc905a8`).
2. Pick the job from the request and run it as the manual describes:
   - "statics for <client>" → 3.1 · "more like the winner" / "adapt" → 3.2
   - "edit this footage" → 3.3 (leadthru-ad-editor + capcut-captions skills)
   - "hooks on <ad>" → 3.4 · "script" / "filming brief" → 3.5
   - scheduled run / "check requests" → section 6
3. Forge never touches an ad account. Everything stops at Awaiting approval in
   the Creative Library; Nucleus launches what Shayan approves.
4. Never write ad data, client numbers or account IDs into this repository.
